# 日常账本 1.5（安卓 · 屏幕扫描版）

本地消费账本，支持日历明细、月总和周总直角柱状图。支持 Android 8.0 及以上。截图仅在内存中离线识别，不保存、不上传。无需通知监听或无障碍服务。

## 安装

先在旧版导出账本备份，再将 output/daily-ledger-1.5.0.apk 发到手机覆盖安装，不要卸载旧版。应用标识、签名保持一致，已入账记录保留。这是个人试用调试版。

## 本次调整

- 备忘录改为一句话待办，新增时只填事项，不再分标题和正文。旧标题与正文在清单中完整合并显示，原记录不会在升级时被改写。
- 清单／四象限两个视图。四象限为重要且紧急、重要不紧急、紧急不重要、不紧急不重要，每个象限 3×3 共 9 格，总计 36 格。
- 在四象限视图拖动清单右侧 ⠿ 或已有方块到空格；也可以点空格选择已有事项或新增。格子已占用时拒绝覆盖，事项不会丢失。事项清单单独滚动。
- 方块默认取事项首字，辅以短文字。点击方块可查看完整内容、编辑单字标识、移出象限或删除。
- 点击圆圈完成事项：变灰、加删除线、自动移至已完成区，腾出象限位置。再次点击恢复未完成，原格子不自动占回。
- 位置、标识和完成状态随备份保存。导入遇到位置冲突时保留原占位，新导入事项进入未分配清单。最多 1000 条事项，每条文字最多 10101 字（兼容旧标题＋正文）。
- 扫描、日历和支出统计保持原有行为。请使用新版导入包含四象限信息的备份，旧版不认识新字段。

## 扫描使用步骤

1. 打开“设置”，允许显示悬浮窗。此权限由你在系统设置开启。
2. 设置账单备用月份，支付方式自动识别。旧账单不显示年份时使用备用月份的年份，因此扫描旧账单前请先设置。
3. 点击开启扫描，在系统弹窗确认屏幕共享。每次重新开启扫描会话都需要系统授权，不能跳过。无需开启无障碍辅助功能。
4. 切到微信或支付宝账单列表，保留列表标题和完整的商户、金额、日期、时间，停止滑动后点击“扫描”。无需切换支付方式。请保留列表顶部搜索栏、筛选栏：微信的“全部账单 / 查找交易”、支付宝的“搜索交易记录 / 筛选”等用于判断来源。顶部控件被遮挡或来源不明确时，显示顶部后重扫。
5. 扫描时悬浮条暂时隐藏，识别后恢复并提示新增、重复数量。手动翻页后再次扫描，重复来源会跳过。
6. 点击“账本”返回待核对列表并结束本次共享。忽略直接移除；编辑可改金额、日期、分类等；核对直接入账。疑似重复会在卡片内提示，确认属于另一笔真实消费后再勾选入账。
7. 点击“×”、账本的停止按钮或系统共享停止入口，结束扫描。锁屏或系统收回共享后，需要重新开启。

仅点击扫描时采集画面，空闲时不采集图像；不自动翻页、不操作支付。屏幕共享期间系统会显示状态提示。禁止截屏的受保护页面无法识别，需手动补记。真实效果仍受支付软件版本、字体和遮挡影响。

## 统计、去重与备份

点击日历日期查看逐笔明细，可编辑、删除或补记。周统计从周一开始，跨月周只计所选月内日期。当前月日均按已过天数计算，其他月按整月天数计算。

扫描按支付方式、日期、分钟、金额、商户生成来源编号，忽略空格和标点差异；已扫、已入账或已忽略来源再次扫描会跳过。同方式、时间和金额与其他记录相撞时提示疑似重复。没有交易单号的列表无法可靠区分同一分钟、同金额、同商户的真实两笔交易，漏掉的第二笔可手动补记。OCR 误识别也可能影响去重。

只接受明确支出，跳过已退款、已退还、失败或日期时间不完整的行。入账后发生退款不会自动改写历史记录，需要手动调整。待核对上限 1,000 条，忽略来源保留最近 10,000 个。

“设置”可导出、导入 JSON。备份包含已入账记录、来源编号和备忘录，不包含待核对及忽略列表。导入去重且保留已有记录；兼容旧备份。卸载、清除数据或换手机前请导出。

## 构建和验证

环境：JDK 21、Gradle 8.11.1、Android Gradle Plugin 8.9.2、SDK Platform 35、Build Tools 35.0.0。本机工具在 .tools/，不打包进 APK。离线中文模型 com.google.mlkit:text-recognition-chinese:16.0.1 随包提供，因此安装包约 47 MB。Manifest 移除了联网权限。

运行 powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1 生成安装包；node --test tests/core.test.cjs 检查账本计算。Java 测试位于 tests/BillParserTest.java、tests/ScanIdentityTest.java、tests/LedgerStoreTest.java，覆盖自动识别支付方式、解析、去重、候选编辑和入账，以及备忘录持久化、编辑、删除、备份去重和导入失败回滚。

node scripts/preview.cjs 可启动电脑界面预览，地址 http://127.0.0.1:4173。预览记录与手机独立，不支持原生扫描。

已完成解析样例、数据逻辑测试和安卓构建、静态检查。尚未在真我 GT7 Pro 上实测屏幕授权、真实 OCR 和覆盖安装，样例通过不代表所有页面均能识别。
