# 日常账本 1.1（安卓 · 悬浮扫描版）

手机上的本地消费账本，保留日历明细、月总和周总直角柱状图。1.1 已删除通知监听，改为点击悬浮窗扫描微信、支付宝账单列表。应用不需要账号；截图在内存中识别后释放，不保存、不上传。基础记账支持 Android 8.0 及以上；屏幕 OCR 需要 Android 11 及以上。

## 安装和使用

1. 在旧版里先导出账本备份，再将 `output/日常账本-1.1.apk` 发到手机直接覆盖安装，**不要先卸载旧版**。升级沿用应用标识和签名，已入账记录保留；旧的未确认通知候选会移除。该文件是个人试用调试版。
2. 打开“日常账本”，点击“记一笔”输入金额、日期、时间、微信 / 支付宝 / 其他支付方式、分类和备注。
3. “账单日历”显示所选月份每天的总支出；点击日期查看当天每一笔记录，可以编辑、删除或补记。
4. “花销统计”中的“周总”显示所选月每周支出，“月总”显示所选年 12 个月的支出。柱子为直角矩形。点击周柱查看明细，点击月柱进入该月周统计。
5. 周统计以周一开始，跨月的一周只计所选月内日期。所有周总相加等于当月总支出。日均按当月已过天数计算，其他月份按整月天数计算。今日支出始终指今天。

## 悬浮扫描（真我 GT7 Pro 等安卓手机）

1. 打开“我的账本 → 悬浮账单扫描 → ① 开启无障碍服务”，阅读应用内用途说明，在系统无障碍设置中找到“日常账本 · 悬浮账单扫描”并开启。不同 realme UI 版本的菜单名可能不同，可在系统设置搜索“无障碍”。
2. 返回账本，设置要扫描的账单月份，点击“② 打开悬浮窗”。年份/月头不在屏幕上时会使用该备用月份；扫描旧月份前请修改，避免把往年同月记到今年。
3. 切到微信“账单”列表（用户提供的截图页面）或支付宝“账单”列表。保留账单标题、完整商户、金额、日期与时间；停止滑动后点击悬浮窗“扫描当前账单”。
4. 悬浮窗显示新增待核对、已记录/已扫、疑似重复数量。向上翻页后可以再次扫描，重叠显示的相同账单不会再次进入队列。悬浮窗标题可拖动。
5. 点击“回账本核对”。核对扫描结果后，可以批量入账明确的新记录；疑似重复需单独对比。修改分类、金额或备注后也可以入账。识别结果不会在未经确认时直接计入花销。
6. 用悬浮窗“关闭”或账本中的“关闭悬浮窗”停止扫描入口。系统无障碍服务可随时关闭。

- 只在点击扫描时读取当前页面；不持续监听、不自动翻页、不点击付款、不读取聊天数据库或支付账号密码。
- Android 11 及以上使用 APK 内置的中文 OCR 模型，无需 Google Play 动态下载模型；Android 8–10 仅尝试读取页面公开的文字节点。
- 仅接受有明确负号的支出行，跳过收入、已退还、已退款、失败、已关闭或日期时间不完整的行。月度汇总金额不会当成一笔消费。
- 截图中的 `+3.50`、`+50.00` 和标注“对方已退还”的 `-3.50` 均不作为新支出。已入账后才发生的退款不会自动改写历史支出，需要手动编辑或删除原记录。
- 微信/支付宝版本、字体大小、遮挡和文字识别误差会影响效果。受系统保护、禁止截屏的页面不能扫描；请手动补记，不会绕过保护。
- 从 APK 安装的应用，部分系统可能要求先在应用信息页面允许受限制的设置，才能开启无障碍服务。权限只能由本人开启。若系统阻止，请根据系统实际提示操作。

## 重复核对规则

- 按支付方式、消费日期、时间（分钟）、金额和商户文字生成来源编号；识别时忽略商户排版中的空格和标点。再次扫描相同来源，或扫描到已入账/已忽略的来源，会跳过。
- 与手动记录的同支付方式、同日期、同时间和金额相撞时，提示“疑似重复”，不直接删除真实消费，也不在批量操作中强行入账。
- 列表没有交易单号，无法可靠区分同一分钟、同金额、同商户的两笔真实交易；被跳过的真实第二笔请手动补记。文字识别错误也可能导致漏判重复，入账前仍需核对。
- 忽略来源最多保留最近 10,000 个，超过后较早忽略的记录可能再次出现。待核对最多 1,000 条，队列满后请先处理，再重扫未加入的页面。

## 备份

“我的账本”支持 JSON 导出和导入。导出包含已入账记录和扫描来源编号，不包含待核对扫描或忽略列表。导入按账单编号和扫描来源去重，并保留已有记录。兼容旧版备份。卸载、清除数据或换手机前请先导出。手机和电脑预览的记录各自独立，可通过备份迁移。

## 开发与验证

- JDK 17 或更高（本机使用 JDK 21）。
- Gradle 8.11.1、Android Gradle Plugin 8.9.2。
- Android SDK Platform 35 和 Build Tools 35.0.0。
- 中文离线识别依赖 `com.google.mlkit:text-recognition-chinese:16.0.1`，联网权限在合并 Manifest 时移除。模型随 APK 打包，因此体积比 1.0 大。
- 账单金额以整数“分”计算，单笔上限 9,999,999.99 元，最多 50,000 笔。
- 本机工具位于 `.tools/`，不属于应用内容。SDK 与 Gradle 不会被打包进 APK。

在项目目录运行 `powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1` 生成安装包；也可在 Android Studio 中打开该项目并使用 Gradle 8.11.1。

运行 `node --test tests/core.test.cjs` 检查金额、日期、周/月合计及备份来源保留。`tests/BillParserTest.java` 和 `tests/ScanIdentityTest.java` 分别验证账单行解析和重复核对，可与对应 Java 类一起用 javac 编译。

运行 `node scripts/preview.cjs` 后在电脑打开 http://127.0.0.1:4173，预览相同界面。电脑预览保存在浏览器 localStorage，不支持安卓悬浮扫描。

测试覆盖账单行几何样例、金额日期、重复核对、备份兼容及安卓编译和静态检查。当前没有连接可调试的手机；尚未在真我 GT7 Pro 上实测无障碍授权、真实 OCR 输出和覆盖安装。样例测试不代表对所有账单页面都能成功识别。

接口参考：[Android AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)、[ML Kit 中文文字识别](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)。
