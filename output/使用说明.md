# 日常账本（安卓）

手机上的本地消费账本，最低支持 Android 8.0。没有联网权限，不上传账单，不需要账号。界面由应用内置 WebView 显示，记录通过安卓本地存储保存。

## 安装和使用

1. 把 `output/日常账本-1.0.apk` 发送到安卓手机，点击安装。该文件是个人试用调试版，不是应用商店发布版。
2. 打开“日常账本”，点击“记一笔”输入金额、日期、时间、微信 / 支付宝 / 其他支付方式、分类和备注。
3. “账单日历”显示所选月份每天的总支出；点击日期查看当天每一笔记录，可以编辑、删除或补记。
4. “花销统计”中的“周总”显示所选月每周支出，“月总”显示所选年 12 个月的支出。柱子为直角矩形。点击周柱查看明细，点击月柱进入该月周统计。
5. 周统计以周一开始，跨月的一周只计所选月内日期。所有周总相加等于当月总支出。日均按当月已过天数计算，其他月份按整月天数计算。今日支出始终指今天。

## 微信、支付宝支付通知

在“我的账本 → 支付通知识别 → 打开通知使用权设置”中，开启“日常账本”的通知使用权。此权限需要本人在系统设置中授权，软件不会自行开启。

- 仅识别微信、支付宝发布的、包含明确支付成功 / 支出字样与人民币金额的通知。
- **识别金额先进入“待确认支付”，核对并入账后才计入统计。** 可以修改金额、消费时间、分类与备注，也可以忽略误识别通知。
- 不读取两款支付软件的历史账单、聊天数据库、账号或密码。
- 微信、支付宝不保证每次消费都向系统发出带金额的通知。应用内支付提示、被隐藏的金额、系统限制、通知模板变化均可能造成漏识别；漏记请手动补记。
- 收款、退款、红包、失败、待支付和包含多个不同金额的通知不会自动提取。退款需要手动编辑原支出为退款后的净金额，全部退款可删除原支出。
- 待确认记录最多 1000 条，请及时处理；同一通知事件会去重，但不同事件或应用重复发送仍需人工核对。
- 从 APK 安装的应用在某些安卓版本上可能需要在系统“应用信息”中允许受限制的设置，才能授予通知使用权。厂商后台限制也可能影响识别。

## 备份

“我的账本”支持 JSON 导出和导入。导出包含已入账记录，不包含待确认通知；导入按记录编号去重并保留已有记录。卸载、清除数据或换手机前请先导出。手机和电脑预览的记录各自独立，可通过备份迁移。

## 开发与验证

- JDK 17 或更高（本机使用 JDK 21）。
- Gradle 8.11.1、Android Gradle Plugin 8.9.2。
- Android SDK Platform 35 和 Build Tools 35.0.0。
- 无第三方运行时依赖；账单金额以整数“分”计算，单笔上限 9,999,999.99 元，最多 50,000 笔。
- 本机工具位于 `.tools/`，不属于应用内容。SDK 与 Gradle 不会被打包进 APK。

在项目目录运行 `powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1` 生成安装包；也可在 Android Studio 中打开该项目并使用 Gradle 8.11.1。

运行 `node --test tests/core.test.cjs` 检查金额、日期、周/月合计和备份规则。`tests/PaymentParserTest.java` 可与 `PaymentParser.java` 一起用 javac 编译，包含通知解析测试。

运行 `node scripts/preview.cjs` 后在电脑打开 http://127.0.0.1:4173，预览相同界面。电脑预览保存在浏览器 localStorage，不支持安卓通知识别。

目前验证范围：编译、静态检查、核心逻辑与通知样例。还需在真实安卓手机上验证安装、显示、备份文件选择器以及微信/支付宝实际通知。不能据样例测试保证所有通知都能识别。

Android 通知接口参考：https://developer.android.com/reference/android/service/notification/NotificationListenerService
